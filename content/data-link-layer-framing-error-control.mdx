# Data Link Layer: Framing, Flow Control, and Error Detection

The Data Link Layer (Layer 2 of the OSI reference model) provides node-to-node reliable frame transmission across physical links. In **UGC NET** and **Bihar STET**, numerical problems consistently feature CRC polynomial division, maximum channel efficiency, sequence number sizing, and framing overhead.

---

## 1. Framing Methods

The Data Link Layer packs raw bitstreams from the Physical Layer into distinct discrete units called **frames**.

1. **Character Count**: First field in frame header indicates total characters in the frame.
   - *Weakness*: If the count field is corrupted by transmission noise, synchronization is completely lost across all subsequent frames.
2. **Byte Stuffing (Character-Oriented)**: Frames begin and end with special `FLAG` bytes (e.g., `0x7E`).
   - If `FLAG` or `ESC` occurs inside the data payload, sender inserts an escape byte (`ESC`).
   - Receiver strips the escape byte to recover raw data.
3. **Bit Stuffing (Bit-Oriented, e.g. HDLC)**:
   - Frame delimiters: Flag byte pattern `01111110` (six consecutive 1s).
   - **Sender Rule**: Whenever the sender encounters **five consecutive 1s** (`11111`) in data, it automatically injects a `0` bit immediately after.
   - **Receiver Rule**: Whenever the receiver sees five consecutive 1s followed by a `0`, it strips the `0` bit. If followed by a `1`, it checks for the ending Flag `01111110`.

## 2. Error Detection & Correction Mechanisms

### 2.1 Hamming Distance Invariants
The Hamming distance $d(x, y)$ is the count of bit positions where codewords $x$ and $y$ differ.
- To **detect** $s$ bit errors: Minimum Hamming distance $d_{\min} \ge s + 1$.
- To **correct** $t$ bit errors: Minimum Hamming distance $d_{\min} \ge 2t + 1$.

### 2.2 Cyclic Redundancy Check (CRC)
CRC treats bitstrings as polynomials with binary coefficients modulo 2 (XOR addition/subtraction without carry).
- **Sender**: Given data polynomial $M(x)$ of length $m$ and generator polynomial $G(x)$ of degree $r$:
  1. Append $r$ zeros to data: $M(x) \cdot x^r$.
  2. Divide $M(x) \cdot x^r$ by $G(x)$ using modulo-2 binary division.
  3. The $r$-bit remainder $R(x)$ is the CRC checksum.
  4. Transmit Codeword $T(x) = M(x) \cdot x^r + R(x)$.
- **Receiver**: Divides received bitstream by identical $G(x)$. If remainder is strictly zero, no error detected.

<Callout type="tip">
**Properties of Generator Polynomial $G(x)$**:
- Detects all single-bit errors if $G(x)$ contains at least two non-zero terms.
- Detects all odd numbers of bit errors if $G(x)$ contains $(x + 1)$ as a factor.
- Detects all burst errors of length $\le r$ (where $r$ is the degree of $G(x)$).
</Callout>

## 3. Sliding Window Flow Control Protocols

Flow control prevents a fast sender from overwhelming a slow receiver buffer.

| Metric | Stop-and-Wait | Go-Back-N (GBN) | Selective Repeat (SR) |
| :--- | :--- | :--- | :--- |
| **Sender Window Size ($W_s$)** | $1$ | $2^k - 1$ | $2^{k-1}$ |
| **Receiver Window Size ($W_r$)** | $1$ | $1$ | $2^{k-1}$ |
| **Out-of-order buffering** | No | No (discarded) | Yes (buffered) |
| **Negative ACK (NACK)** | No | No | Yes |
| **Retransmission Scope** | 1 frame (timeout) | Retransmit window from lost frame | Retransmit **only** lost frame |
| **Channel Efficiency ($\eta$)** | $\frac{1}{1 + 2a}$ | $\frac{W_s}{1 + 2a} \le 1.0$ | $\frac{W_s}{1 + 2a} \le 1.0$ |

*(where $a = \frac{T_{\text{prop}}}{T_{\text{trans}}} = \frac{d / v}{L / B}$)*

---

## 4. Medium Access Control: CSMA/CD

In Carrier Sense Multiple Access with Collision Detection:
- Stations sense carrier before transmitting.
- To detect a collision before transmission concludes, frame transmission duration must satisfy:
$$T_{\text{trans}} \ge 2 \cdot T_{\text{prop}} = \text{RTT}$$
$$\frac{L_{\min}}{\text{Bandwidth}} \ge 2 \cdot \left(\frac{\text{Distance}}{v}\right) \implies L_{\min} \ge 2 \cdot T_{\text{prop}} \cdot B$$
