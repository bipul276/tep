# Boolean Algebra, Karnaugh Maps (K-Maps), Prime Implicants & Combinational Logic

## 1. Boolean Algebra Theorems & Laws

Boolean algebra, formulated by **George Boole** in 1854, provides the algebraic foundation for all digital hardware circuits. Variables take values from the binary set $\{0, 1\}$.

### 1.1 Master List of Theorems & Postulates

| Law / Theorem | AND Form ($\cdot$) | OR Form ($+$) |
|---|---|---|
| **Identity Law** | $A \cdot 1 = A$ | $A + 0 = A$ |
| **Null (Domination) Law** | $A \cdot 0 = 0$ | $A + 1 = 1$ |
| **Idempotent Law** | $A \cdot A = A$ | $A + A = A$ |
| **Complement Law** | $A \cdot \bar{A} = 0$ | $A + \bar{A} = 1$ |
| **Involution (Double Negation)** | $\overline{\bar{A}} = A$ | — |
| **Commutative Law** | $A \cdot B = B \cdot A$ | $A + B = B + A$ |
| **Associative Law** | $(A \cdot B) \cdot C = A \cdot (B \cdot C)$ | $(A + B) + C = A + (B + C)$ |
| **Distributive Law** | $A \cdot (B + C) = (A \cdot B) + (A \cdot C)$ | **$A + (B \cdot C) = (A + B) \cdot (A + C)$** |
| **Absorption Law** | $A \cdot (A + B) = A$ | $A + (A \cdot B) = A$ |
| **De Morgan's Laws** | $\overline{A \cdot B} = \bar{A} + \bar{B}$ | $\overline{A + B} = \bar{A} \cdot \bar{B}$ |

> **High-Frequency Exam Postulate**:
> The second distributive law:
> $$A + BC = (A + B)(A + C)$$
> does not hold in standard real-number algebra, but is **strictly true in Boolean algebra**.

---

### 1.2 The Consensus Theorem (Redundancy Law)

The Consensus Theorem allows the elimination of redundant product terms:

$$AB + \bar{A}C + BC = AB + \bar{A}C$$

- **Identification Rule**: Look for three variables ($A, B, C$) where one variable ($A$) appears both uncomplemented ($A$) and complemented ($\bar{A}$). The third term ($BC$), composed of the remaining two variables, is **completely redundant** and can be eliminated!
- **Dual (POS) Form**:
$$(A + B)(\bar{A} + C)(B + C) = (A + B)(\bar{A} + C)$$

## 2. Canonical and Standard Forms

A boolean function of $n$ variables can be represented in two canonical forms:

### 2.1 Minterms and Maxterms

- **Minterm ($m_i$)**: A product (AND) of all $n$ variables, each appearing in either its uncomplemented or complemented form. A minterm evaluates to **1** for exactly one combination of input values.
- **Maxterm ($M_i$)**: A sum (OR) of all $n$ variables. A maxterm evaluates to **0** for exactly one combination.
- **Fundamental Invariant**:
$$m_i = \overline{M_i}$$

| $A$ | $B$ | $C$ | Index $i$ | Minterm ($m_i$) | Maxterm ($M_i$) |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 0 | 0 | 0 | 0 | $\bar{A}\bar{B}\bar{C}$ | $A + B + C$ |
| 0 | 0 | 1 | 1 | $\bar{A}\bar{B}C$ | $A + B + \bar{C}$ |
| 0 | 1 | 0 | 2 | $\bar{A}B\bar{C}$ | $A + \bar{B} + C$ |
| 0 | 1 | 1 | 3 | $\bar{A}BC$ | $A + \bar{B} + \bar{C}$ |
| 1 | 0 | 0 | 4 | $A\bar{B}\bar{C}$ | $\bar{A} + B + C$ |
| 1 | 0 | 1 | 5 | $A\bar{B}C$ | $\bar{A} + B + \bar{C}$ |
| 1 | 1 | 0 | 6 | $AB\bar{C}$ | $\bar{A} + \bar{B} + C$ |
| 1 | 1 | 1 | 7 | $ABC$ | $\bar{A} + \bar{B} + \bar{C}$ |

- **Sum of Minterms (SOP)**: $F(A, B, C) = \sum m(1, 3, 5, 7)$
- **Product of Maxterms (POS)**: $F(A, B, C) = \prod M(0, 2, 4, 6)$

## 3. Karnaugh Maps (K-Maps)

Developed by **Maurice Karnaugh** at Bell Labs in 1953, a K-Map is a pictorial method of grouping adjacent minterms to produce minimal algebraic expressions.

### 3.1 Principle of Gray Code Adjacency
Cells in a K-Map are ordered using **Gray Code** ($00, 01, 11, 10$) so that **physically adjacent cells differ by exactly ONE binary bit**.

```text
3-Variable K-Map (A on rows, BC on columns):
          BC
 A \      00      01      11      10
    +-------+-------+-------+-------+
 0  |  m₀   |  m₁   |  m₃   |  m₂   |
    +-------+-------+-------+-------+
 1  |  m₄   |  m₅   |  m₇   |  m₆   |
    +-------+-------+-------+-------+
```

```text
4-Variable K-Map (AB on rows, CD on columns):
          CD
 AB \     00      01      11      10
    +-------+-------+-------+-------+
 00 |  m₀   |  m₁   |  m₃   |  m₂   |
    +-------+-------+-------+-------+
 01 |  m₄   |  m₅   |  m₇   |  m₆   |
    +-------+-------+-------+-------+
 11 |  m₁₂  |  m₁₃  |  m₁₅  |  m₁₄  |
    +-------+-------+-------+-------+
 10 |  m₈   |  m₉   |  m₁₁  |  m₁₀  |
    +-------+-------+-------+-------+
```

### 3.2 Grouping Rules
1. Groups must contain a **power of 2** cells ($1, 2, 4, 8, 16$).
2. Groups must be rectangular or square.
3. Groups can **wrap around** edges and corners (e.g., the 4 corners $m_0, m_2, m_8, m_{10}$ form a valid group of 4!).
4. Larger groups yield smaller algebraic terms:
   - Group of 1 cell $\implies 4$ literal term.
   - Group of 2 cells $\implies 3$ literal term.
   - Group of 4 cells $\implies 2$ literal term.
   - Group of 8 cells $\implies 1$ literal term.

## 4. Prime Implicants (PI) vs. Essential Prime Implicants (EPI)

These definitions are among the most frequently tested concepts in computer science competitive exams:

```text
+-------------------------------------------------------------+
| Implicant: Any single minterm or group of minterms where F=1|
|  +-------------------------------------------------------+  |
|  | Prime Implicant (PI): Maximal group of 2ᵏ minterms    |  |
|  | that cannot be combined into any larger group         |  |
|  |  +-------------------------------------------------+  |  |
|  |  | Essential Prime Implicant (EPI):                |  |  |
|  |  | Contains at least one '1' not covered by ANY   |  |  |
|  |  | other Prime Implicant (Unique coverage)         |  |  |
|  |  +-------------------------------------------------+  |  |
|  +-------------------------------------------------------+  |
+-------------------------------------------------------------+
```

### 4.1 Step-by-Step Worked Example: Finding PIs and EPIs

**Function**: $F(A, B, C, D) = \sum m(0, 2, 5, 7, 8, 10, 14, 15)$

1. **Locate groups of 4 (Quads)**:
   - Four Corners: $\{m_0, m_2, m_8, m_{10}\} \implies \bar{B}\bar{D}$
   - Middle Quad: $\{m_5, m_7, m_{13}^* \text{ (not in } F)\}$ $\implies$ Pair $\{m_5, m_7\} \implies \bar{A}BD$
   - Bottom Row: Pair $\{m_{14}, m_{15}\} \implies AB C$
2. **Identify all Prime Implicants (PIs)**:
   - $PI_1 = \bar{B}\bar{D}$ (covers $0, 2, 8, 10$)
   - $PI_2 = \bar{A}BD$ (covers $5, 7$)
   - $PI_3 = ABC$ (covers $14, 15$)
3. **Identify Essential Prime Implicants (EPIs)**:
   - Minterm $5$ is covered ONLY by $\bar{A}BD \implies \bar{A}BD$ is an **EPI**.
   - Minterm $14$ is covered ONLY by $ABC \implies ABC$ is an **EPI**.
   - Minterm $0$ is covered ONLY by $\bar{B}\bar{D} \implies \bar{B}\bar{D}$ is an **EPI**.
   - **All 3 PIs are Essential!**
   - Minimal SOP expression:
$$F = \bar{B}\bar{D} + \bar{A}BD + ABC$$

## 5. Don't Care Conditions ($X$ or $d$)

In certain digital designs, specific input combinations can **never physically occur**, or their output has no effect on system operation. These are called **Don't Care conditions**:

$$F(A, B, C, D) = \sum m(\dots) + \sum d(\dots)$$

- **Rule**: In a K-Map, a Don't Care ($X$) is treated as a **1** IF it helps form a larger group (reducing term complexity). If it does not help, it is treated as a **0** and ignored.

## 6. Combinational Logic Circuits

### 6.1 Multiplexer (Data Selector)

A $2^n$-to-1 Multiplexer routes one of $2^n$ data inputs to a single output line based on the binary value of $n$ selection lines:

```text
                   2ⁿ-to-1 Multiplexer
                 +---------------------+
     I₀ -------->|                     |
     I₁ -------->|                     |
        -------->|                     |-------> Output Y
   I_{2ⁿ-1} ---->|                     |
                 +---------------------+
                            | |
                         S_{n-1} S₀ (n Select Lines)
```

#### Implementing Arbitrary Logic with a MUX:
Any $n$-variable boolean function can be implemented using a **$2^{n-1}$-to-1 MUX** (using $n-1$ variables for select lines, and connecting the remaining variable $C, \bar{C}, 0,$ or $1$ to data inputs).

---

### 6.2 Decoders & Adders

- **$n$-to-$2^n$ Decoder**: Decodes an $n$-bit input code into one of $2^n$ active output lines (each output corresponds to a minterm).
- **Half Adder**:
$$\text{Sum} = A \oplus B, \quad \text{Carry} = A \cdot B$$
- **Full Adder**:
$$\text{Sum} = A \oplus B \oplus C_{\text{in}}$$
$$C_{\text{out}} = AB + BC_{\text{in}} + AC_{\text{in}} = AB + C_{\text{in}}(A \oplus B)$$
  *(A Full Adder can be constructed using **two Half Adders and one OR gate**).*

## 7. UGC NET & Bihar STET PYQ Practice Patterns

### Question 1 (UGC NET Dec 2018 — Consensus Theorem)
Simplify the Boolean expression:
$$F = AB + \bar{A}C + BC$$

**Solution**:
- Apply Consensus Theorem directly:
  - Variable $A$ appears uncomplemented in $AB$ and complemented in $\bar{A}C$.
  - The third term $BC$ consists of the remaining variables.
  - Therefore, $BC$ is redundant:
$$F = AB + \bar{A}C$$
**Answer**: $AB + \bar{A}C$.

### Question 2 (UGC NET 2020 — Full Adder Gate Count)
How many 2-input NAND gates are required to implement a Full Adder?

**Solution**:
- A Half Adder requires 5 NAND gates.
- A Full Adder requires **9 NAND gates** (or 2 Half Adders + 1 OR gate $= 5 + 5 - 1 = 9$ gates).
**Answer**: **9 NAND gates**.

### Question 3 (UGC NET 2021 — Multiplexer Sizing)
How many 4-to-1 multiplexers are required to construct a 16-to-1 multiplexer?

**Solution**:
- Stage 1: $\frac{16}{4} = 4$ multiplexers.
- Stage 2: $\frac{4}{4} = 1$ multiplexer.
- Total MUX required: $4 + 1 = \mathbf{5}$.
**Answer**: 5.
