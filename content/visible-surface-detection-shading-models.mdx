# Visible Surface Detection, Hidden Surface Removal, and Shading Models

Visible surface detection (hidden surface removal) and surface illumination shading are high-frequency scoring topics in the **UGC NET Computer Science** examination (Unit 15). This topic covers object-space vs. image-space algorithms, Z-buffer mathematical formulation, and illumination models (Flat, Gouraud, and Phong shading).

---

## 1. Classification of Hidden Surface Removal Algorithms

Hidden surface removal determines which surfaces and surface parts are visible from a chosen viewpoint.

### 1.1 Object-Space vs. Image-Space Methods
- **Object-Space Methods**: Operate at arbitrary precision in the physical object coordinate space. Compare objects directly against each other ($O(N^2)$ complexity for $N$ polygons). Example: **Back-Face Culling**.
- **Image-Space Methods**: Operate on discrete pixel coordinates on the projection view plane ($O(N \cdot P)$ complexity for $N$ polygons and $P$ display pixels). Examples: **Depth-Buffer (Z-buffer)**, **Scan-Line**, **A-buffer**.

---

## 2. Core Hidden Surface Removal Algorithms

### 2.1 Back-Face Culling (Object-Space)
For a polygon with outward surface normal vector $\mathbf{N} = (A, B, C)$ and viewing direction vector $\mathbf{V}_{\text{view}} = (0, 0, 1)$:
A polygon is a back face (hidden from view) if:
$$\mathbf{N} \cdot \mathbf{V}_{\text{view}} = C \le 0 \quad (\text{or in camera coordinates, } \mathbf{N} \cdot \mathbf{V} > 0)$$
- **Efficiency**: Eliminates roughly **50% of polygons** from a closed polyhedron before rasterization begins!

### 2.2 Depth-Buffer (Z-Buffer) Algorithm (Image-Space)
Uses two 2D memory arrays:
1. **Frame Buffer (`intensity[x, y]`)**: Stores color intensity for every pixel $(x, y)$.
2. **Depth Buffer (`z_buffer[x, y]`)**: Stores minimum $z$-distance from viewpoint for every pixel $(x, y)$.

```
Initialize: z_buffer[x, y] = -∞ (or 1.0), intensity[x, y] = Background_Color

For each polygon P:
  For each pixel (x, y) covered by P:
    Calculate depth z at (x, y)
    If z > z_buffer[x, y]:  // Point is closer to camera
      z_buffer[x, y] = z
      intensity[x, y] = Color_P(x, y)
```

- **Incremental Depth Calculation**: If polygon plane equation is $Ax + By + Cz + D = 0$:
$$z = \frac{-Ax - By - D}{C}$$
  Moving one pixel right ($x + 1$):
$$z' = z - \frac{A}{C}$$

<Callout type="note">
**Advantages & Limitations of Z-Buffer**:
- *Advantage*: Very simple, easily implemented in GPU hardware; processes polygons in arbitrary order.
- *Limitation*: Memory intensive ($O(P)$ memory); cannot handle transparent surfaces natively (handled by **A-Buffer**).
</Callout>

### 2.3 Painter's Algorithm (Depth-Sort)
1. Sort all polygons in order of decreasing distance from viewpoint (largest $z_{\min}$ first).
2. Draw polygons on screen from back to front, overwriting earlier pixels.
- *Ambiguity*: Fails when polygons have cyclical overlaps ($A$ overlaps $B$, $B$ overlaps $C$, $C$ overlaps $A$) or pierce each other, requiring polygon splitting.

## 3. Illumination and Shading Models

Shading determines color intensity across polygon surfaces under ambient, diffuse, and specular illumination.

$$\text{Phong Illumination: } I = I_a k_a + I_d k_d (\mathbf{N} \cdot \mathbf{L}) + I_s k_s (\mathbf{R} \cdot \mathbf{V})^n$$

### 3.1 Comparison of Shading Techniques

| Metric | Flat (Constant) Shading | Gouraud (Intensity Interpolation) | Phong (Normal Vector Interpolation) |
| :--- | :--- | :--- | :--- |
| **Normal Vector** | 1 normal per polygon | Averaged vertex normals: $\mathbf{N}_v = \frac{\sum \mathbf{N}_i}{\Vert \sum \mathbf{N}_i \Vert}$ | Normal interpolated at **every interior pixel** |
| **Calculation Point** | Center of polygon | At each vertex, then linearly interpolated | At each pixel across polygon |
| **Specular Highlights** | Poor / Absent | Distorted / Missed if highlight lies inside polygon | **Accurate, realistic specular highlights** |
| **Mach Banding** | Severe | **Present** (due to continuous $C^0$ intensity derivative slope discontinuity) | **Eliminated** ($C^1$ smooth normal interpolation) |
| **Computational Cost** | Lowest | Medium | Highest |
