# Asymptotic Notation, Master Theorem & Recurrence Relations

## 1. Foundations of Algorithm Complexity Analysis

When analyzing the running time or space utilization of an algorithm, we seek an evaluation that is **machine-independent**, **input-size dependent**, and focused on behavior as the problem size $n$ grows arbitrarily large ($n \to \infty$). This is called **asymptotic analysis**.

Instead of counting physical execution clock cycles, we measure the number of **primitive operations** executed as a function of the input size $n$.

---

## 2. Formal Mathematical Definitions of Asymptotic Notations

Let $f(n)$ and $g(n)$ be functions mapping non-negative integers to non-negative real numbers ($f, g: \mathbb{N} \to \mathbb{R}^+$).

```text
Big-O (Upper Bound)          Big-Omega (Lower Bound)        Big-Theta (Tight Bound)
      c·g(n)                        f(n)                          c₂·g(n)
        ^                            ^                              ^
       /   f(n)                     /   c·g(n)                     / f(n)
      /    /                       /    /                         /  /
     /    /                       /    /                         /  / c₁·g(n)
    /    /                       /    /                         /  /  /
   +----+---> n                 +----+---> n                   +--+--+---> n
        n₀                           n₀                           n₀
```

### 2.1 Big-O Notation: Asymptotic Upper Bound

> **Definition**: $f(n) = O(g(n))$ if and only if there exist positive constants $c > 0$ and $n_0 \ge 1$ such that:
> $$0 \le f(n) \le c \cdot g(n) \quad \forall n \ge n_0$$

- **Intuition**: $g(n)$ is an upper bound on the growth rate of $f(n)$ for sufficiently large $n$. The algorithm will perform **at most** proportional to $g(n)$ steps.

### 2.2 Big-Omega ($\Omega$) Notation: Asymptotic Lower Bound

> **Definition**: $f(n) = \Omega(g(n))$ if and only if there exist positive constants $c > 0$ and $n_0 \ge 1$ such that:
> $$0 \le c \cdot g(n) \le f(n) \quad \forall n \ge n_0$$

- **Intuition**: $g(n)$ is a lower bound on the growth rate of $f(n)$ for large $n$. The algorithm will require **at least** proportional to $g(n)$ steps.

### 2.3 Big-Theta ($\Theta$) Notation: Asymptotically Tight Bound

> **Definition**: $f(n) = \Theta(g(n))$ if and only if there exist positive constants $c_1, c_2 > 0$ and $n_0 \ge 1$ such that:
> $$0 \le c_1 \cdot g(n) \le f(n) \le c_2 \cdot g(n) \quad \forall n \ge n_0$$

- **Theorem**:
$$f(n) = \Theta(g(n)) \iff f(n) = O(g(n)) \quad \text{AND} \quad f(n) = \Omega(g(n))$$

---

### 2.4 Little-o and Little-$\omega$ (Strict Bounds)

| Notation | Formal Definition | Limit Test Criterion ($\lim_{n \to \infty} \frac{f(n)}{g(n)}$) | Analogy with Real Numbers |
|:---:|:---|:---:|:---:|
| **$O(g(n))$** | $\exists c > 0, n_0 : f(n) \le c \cdot g(n)$ | $< \infty$ (finite or zero) | $\le$ |
| **$\Omega(g(n))$** | $\exists c > 0, n_0 : f(n) \ge c \cdot g(n)$ | $> 0$ (positive or $\infty$) | $\ge$ |
| **$\Theta(g(n))$** | $\exists c_1, c_2 > 0, n_0 : c_1 g(n) \le f(n) \le c_2 g(n)$ | $L \in (0, \infty)$ (strictly positive finite constant) | $=$ |
| **$o(g(n))$** | $\forall c > 0, \exists n_0 : f(n) < c \cdot g(n)$ | $= 0$ (Strictly slower growth) | $<$ |
| **$\omega(g(n))$** | $\forall c > 0, \exists n_0 : f(n) > c \cdot g(n)$ | $= \infty$ (Strictly faster growth) | $>$ |

## 3. Algebraic Properties & Invariants

### 3.1 Relational Properties
1. **Transitivity**:
   - $f(n) = \Theta(g(n)) \land g(n) = \Theta(h(n)) \implies f(n) = \Theta(h(n))$ (Also holds for $O, \Omega, o, \omega$).
2. **Reflexivity**:
   - $f(n) = O(f(n))$, $f(n) = \Omega(f(n))$, $f(n) = \Theta(f(n))$.
3. **Symmetry**:
   - $f(n) = \Theta(g(n)) \iff g(n) = \Theta(f(n))$.
4. **Transpose Symmetry**:
   - $f(n) = O(g(n)) \iff g(n) = \Omega(f(n))$.
   - $f(n) = o(g(n)) \iff g(n) = \omega(f(n))$.

## 4. Hierarchy of Standard Growth Rates

Arranged from slowest to fastest growing:

$$O(1) < O(\log \log n) < O(\log n) < O(\sqrt{n}) < O(n) < O(n \log n) < O(n^2) < O(n^3) < O(2^n) < O(e^n) < O(n!) < O(n^n)$$

### 4.1 Essential Logarithmic Identities for Algorithm Ranking
1. **Change of Base**: $\log_a n = \frac{\log_b n}{\log_b a} = \Theta(\log_b n)$. (Base of logarithm inside asymptotic notation does not change polynomial order!).
2. **Power inside Log**: $\log(n^k) = k \log n = \Theta(\log n)$.
3. **Log Raised to Power**: $(\log n)^k \neq \log(n^k)$. For any $k > 0$ and $\epsilon > 0$:
$$(\log n)^k = o(n^\epsilon)$$
   *(Any polynomial, no matter how small the exponent $\epsilon$, grows asymptotically faster than any poly-logarithmic function).*
4. **Power Exchange**: $a^{\log_b n} = n^{\log_b a}$.
5. **Stirling's Formula**:
$$n! \approx \sqrt{2\pi n} \left(\frac{n}{e}\right)^n \implies \log(n!) = \Theta(n \log n)$$

---

### 4.2 Worked Problem: Ranking Competitive Exam Functions

**Task**: Sort the following functions in increasing order of asymptotic growth:
$$f_1(n) = 2^n, \quad f_2(n) = n^{\log_2 c}, \quad f_3(n) = n!, \quad f_4(n) = \log(n!), \quad f_5(n) = n^{1/\log n}$$

**Step-by-step simplification**:
1. $f_5(n) = n^{1/\log_2 n}$:
   Let $y = n^{1/\log_2 n} \implies \log_2 y = \frac{1}{\log_2 n} \cdot \log_2 n = 1 \implies y = 2^1 = 2 = \Theta(1)$ (Constant!).
2. $f_4(n) = \log(n!) = \Theta(n \log n)$.
3. $f_2(n) = n^{\log_2 c} = \Theta(n^k)$ (Polynomial).
4. $f_1(n) = 2^n$ (Exponential).
5. $f_3(n) = n! \approx \sqrt{2\pi n}(n/e)^n = \Theta(n^n)$ (Superexponential).

**Final Ascending Order**:
$$f_5(n) < f_2(n) < f_4(n) < f_1(n) < f_3(n)$$

## 5. Solving Recurrences: The Master Theorem (Divide and Conquer)

The Master Theorem provides a cookbook solution for recurrences of the canonical form:

$$T(n) = a T\left(\frac{n}{b}\right) + f(n)$$

where $a \ge 1$, $b > 1$, and $f(n)$ is an asymptotically positive function.

### 5.1 The Watershed Function
The behavior of the recurrence is determined by comparing the driving function $f(n)$ with the **watershed function**:

$$n^{\log_b a}$$

```
                Comparison: f(n) vs n^(log_b a)
                              |
        +---------------------+---------------------+
        |                     |                     |
        v                     v                     v
   f(n) is SMALLER       f(n) is EQUAL        f(n) is LARGER
 (Polynomial Gap)      (Within log factors)  (Polynomial Gap)
        |                     |                     |
     CASE 1                CASE 2                CASE 3
 T(n) = Θ(n^(log_b a))  T(n) = Θ(n^(log_b a)·log^(k+1) n)  T(n) = Θ(f(n))
```

### 5.2 The Three Cases Formally

#### Case 1: Watershed Dominates (Subproblem Work Dominates)
If $f(n) = O(n^{\log_b a - \epsilon})$ for some constant $\epsilon > 0$:
$$T(n) = \Theta(n^{\log_b a})$$

#### Case 2: Balance (Both Work Equally)
If $f(n) = \Theta(n^{\log_b a} \log^k n)$ for some constant $k \ge 0$:
$$T(n) = \Theta(n^{\log_b a} \log^{k+1} n)$$
*(For the basic case where $f(n) = \Theta(n^{\log_b a})$, $k = 0 \implies T(n) = \Theta(n^{\log_b a} \log n)$).*

#### Case 3: Driving Function Dominates (Root Work Dominates)
If $f(n) = \Omega(n^{\log_b a + \epsilon})$ for some constant $\epsilon > 0$, **AND** the **regularity condition** holds:
$$a f\left(\frac{n}{b}\right) \le c \cdot f(n) \quad \text{for some constant } c < 1 \text{ and sufficiently large } n$$
then:
$$T(n) = \Theta(f(n))$$

---

### 5.3 Pitfalls: Non-Polynomial Gaps (Where Master Theorem Fails)

The gap between $f(n)$ and $n^{\log_b a}$ **must be polynomial** ($n^\epsilon$), not merely logarithmic.

#### Pitfall Example 1:
$$T(n) = 2T\left(\frac{n}{2}\right) + \frac{n}{\log n}$$
- $a = 2, b = 2 \implies n^{\log_2 2} = n^1 = n$.
- $f(n) = \frac{n}{\log n}$.
- Is $f(n)$ polynomially smaller than $n$?
$$\frac{n}{f(n)} = \frac{n}{n/\log n} = \log n \neq n^\epsilon$$
- There is no $\epsilon > 0$ such that $\log n = \Omega(n^\epsilon)$.
- **Master Theorem does NOT apply**! (Solve via substitution or recursion tree $\implies \Theta(n \log \log n)$).

#### Pitfall Example 2:
$$T(n) = 2T\left(\frac{n}{2}\right) + n \log n$$
- $n^{\log_2 2} = n$.
- $f(n) = n \log n$.
- Is $f(n)$ polynomially larger than $n$? $\frac{f(n)}{n} = \log n \neq n^\epsilon$.
- Case 3 does NOT apply! But **Extended Case 2** ($k=1$) applies:
$$T(n) = \Theta(n \log^{1+1} n) = \Theta(n \log^2 n)$$

---

## 6. The Recursion Tree Method

When subproblems are non-uniform or Master Theorem conditions fail, draw a recursion tree.

### 6.1 Worked Analysis: Non-Uniform Recurrence
$$T(n) = T\left(\frac{n}{3}\right) + T\left(\frac{2n}{3}\right) + c n$$

```text
Level 0:                         cn                              Cost = cn
                               /    \
Level 1:                 c(n/3)      c(2n/3)                     Cost = cn
                         /    \      /     \
Level 2:             c(n/9) c(2n/9) c(2n/9) c(4n/9)              Cost = cn
```

1. **Cost per level**: Every complete level sums to exactly $c\left(\frac{n}{3} + \frac{2n}{3}\right) = cn$.
2. **Height of Shortest Branch**: Left-most branch reaches base case when $\frac{n}{3^k} = 1 \implies k_1 = \log_3 n$.
3. **Height of Longest Branch**: Right-most branch reaches base case when $n \left(\frac{2}{3}\right)^{k_2} = 1 \implies k_2 = \log_{3/2} n$.
4. **Asymptotic Bound**:
$$\text{Total Cost} = \sum_{i=0}^{\log_{3/2} n} cn = \Theta(n \log n)$$

## 7. Master Comparison of Classic Recurrences

| Recurrence | Algorithm | Master Theorem Case | Solution |
|---|---|:---:|:---:|
| $T(n) = T(n/2) + O(1)$ | Binary Search | Case 2 ($k=0$) | $\Theta(\log n)$ |
| $T(n) = 2T(n/2) + O(1)$ | Tree Traversal | Case 1 | $\Theta(n)$ |
| $T(n) = 2T(n/2) + O(n)$ | Merge Sort | Case 2 ($k=0$) | $\Theta(n \log n)$ |
| $T(n) = 4T(n/2) + O(n)$ | Divide & Conquer Matrix Mult (Naive) | Case 1 | $\Theta(n^2)$ |
| $T(n) = 7T(n/2) + O(n^2)$ | Strassen's Matrix Multiplication | Case 1 ($n^{\log_2 7} \approx n^{2.81}$) | $\Theta(n^{\log_2 7})$ |
| $T(n) = T(n-1) + O(1)$ | Linear Search | Linear Recurrence | $\Theta(n)$ |
| $T(n) = T(n-1) + O(n)$ | Selection / Insertion Sort | Linear Recurrence | $\Theta(n^2)$ |
| $T(n) = 2T(n-1) + O(1)$ | Tower of Hanoi | Linear Recurrence | $\Theta(2^n)$ |

## 8. UGC NET & Bihar STET PYQ Practice Patterns

### Question 1 (UGC NET 2020)
Solve the recurrence relation:
$$T(n) = 8T\left(\frac{n}{2}\right) + 1000 n^2$$

**Solution**:
- $a = 8, b = 2, f(n) = 1000 n^2 = \Theta(n^2)$.
- Compute watershed: $n^{\log_b a} = n^{\log_2 8} = n^3$.
- Compare $f(n)$ with $n^3$:
$$f(n) = O(n^{3 - \epsilon}) \quad \text{for } \epsilon = 1 \implies \text{Case 1 applies!}$$
**Answer**: $T(n) = \Theta(n^3)$.

### Question 2 (UGC NET 2019)
Which of the following statements is **FALSE**?
- (A) $2^{n+1} = O(2^n)$
- (B) $2^{2n} = O(2^n)$
- (C) $f(n) = O(g(n)) \implies g(n) = \Omega(f(n))$
- (D) $f(n) = \Theta(g(n)) \implies g(n) = \Theta(f(n))$

**Solution**:
- Check (A): $2^{n+1} = 2 \cdot 2^n \le c \cdot 2^n$ (holds for $c = 2$). True.
- Check (B): $2^{2n} = (2^2)^n = 4^n$. Does there exist $c$ such that $4^n \le c \cdot 2^n$?
$$\frac{4^n}{2^n} = 2^n \to \infty \text{ as } n \to \infty$$
  No finite constant $c$ exists. Thus, $2^{2n} \neq O(2^n)$. (B is False!).
- (C) and (D) are standard transpose symmetry and symmetry theorems.
**Answer**: **(B)**.
